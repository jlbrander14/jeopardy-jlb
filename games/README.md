# Adding a game

Each game is a single CSV file in this folder. `host.html` reads
`manifest.json` (generated by `scripts/build-manifest.js`) to know which
games exist, then fetches and parses the chosen file at "Create Room" time.
No database, no build step — just a file per game.

## Format

Two metadata rows, then a table. See [`TEMPLATE.csv`](TEMPLATE.csv) or
[`classic-trivia.csv`](classic-trivia.csv) for real examples.

```
Title,My Game Night
Author,Alice

Round,Category,Value,Clue,Answer,DailyDouble
1,WORLD CAPITALS,200,This city on the Seine is the capital of France.,What is Paris?,
1,WORLD CAPITALS,400,This is the capital of Japan.,What is Tokyo?,
2,GEOGRAPHY,400,This is the longest river in the world.,What is the Nile?,
2,GEOGRAPHY,800,This is the smallest country in the world.,What is Vatican City?,TRUE
Final,WORLD LANDMARKS,,Completed in 1889 as a temporary entrance arch.,What is the Eiffel Tower?,
```

| Column | Meaning |
|---|---|
| `Round` | `1` (Jeopardy Round), `2` (Double Jeopardy Round), or `Final`. Case-insensitive; `Final Jeopardy` also works since only the leading "final" is checked. |
| `Category` | The category name. Every row sharing a category name (within the same round) becomes one column on the board. Not used for `Final`. |
| `Value` | The point value, e.g. `200`. Not used for `Final`. If left blank in Round 1/2, the clue is worth $0 — always fill this in. |
| `Clue` | Shown on the board / read by the host. |
| `Answer` | The correct response, phrased as a question (`What is...?`) for the host's reference — it's never shown to players automatically. |
| `DailyDouble` | `TRUE` to make this clue a Daily Double (host picks who's "in control" and their wager instead of buzzing in). Leave blank otherwise. Not used for `Final`. |

## What's required vs. optional

- **Round 1 is required.** A game with no Round 1 rows fails to load.
- **Round 2 and Final are both optional.** Leave them out entirely (delete
  those rows) for a shorter, one-round game — the host UI adjusts
  automatically (no "Start Double Jeopardy" button if there's no Round 2; a
  "Finish Game" button instead of "Final Jeopardy" if there's no Final row).
- **Category/clue counts don't have to be uniform.** 6 categories × 5 clues
  is the classic layout, but more or fewer both work, and categories don't
  all need the same number of clues (a short category just leaves blank
  cells on the board below its last clue).
- Rows are grouped into categories in the order they first appear, and
  clues within a category are sorted by `Value` — so it doesn't matter what
  order you type them in, but for a normal-looking board keep each
  category's 5 rows together and Value ascending.
- Blank rows are ignored. A row missing `Category`, `Clue`, or `Answer` is
  skipped (logged as a warning in the browser console) rather than crashing
  the load, so one bad row won't break the whole game.

## Making a new game

Easiest path: copy [`TEMPLATE.csv`](TEMPLATE.csv), or send friends
[`Jeopardy-Game-Template.xlsx`](Jeopardy-Game-Template.xlsx) (a proper
spreadsheet with instructions and dropdowns) and have them export the
finished Template tab as CSV.

Once you have a finished `.csv`:

```bash
# 1. Save it into this folder, e.g.:
cp ~/Downloads/alice-movie-night.csv games/

# 2. Regenerate the game list (reads Title/Author from each CSV):
node scripts/build-manifest.js

# 3. Commit and push both files.
git add games/alice-movie-night.csv games/manifest.json
git commit -m "Add Alice's movie night round"
git push
```

The dropdown on `host.html` picks up the new game immediately after that's
deployed — nothing else to configure.

## Validating a game without opening the site

`scripts/build-manifest.js` will warn (but not fail) if a CSV doesn't look
right — e.g. no header row. For a fuller check, load the game in `host.html`
locally (see the root `README.md`'s "Local preview" section) and check the
browser console after clicking "Create Room": any skipped rows are logged
there as warnings even though the game still loads.
